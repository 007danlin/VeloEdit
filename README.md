# VeloEdit

VeloEdit — видеоредактор для macOS с локальным искусственным интеллектом. Он помогает найти лучшие моменты в фото и видео, собрать из них фильм и при необходимости вручную доработать результат на таймлайне.

Приложение работает в первую очередь на самом Mac: исходные файлы не изменяются, а для основного монтажа не нужен облачный сервис.

## Что умеет VeloEdit

- импортировать фото и видео без лишнего копирования;
- анализировать сцены, звук, людей, движение и телеметрию;
- собирать монтаж по обычному запросу на русском языке;
- добавлять музыку, титры, переходы, эффекты и телеметрию;
- учитывать ручные правки и постепенно подстраиваться под стиль пользователя;
- создавать предпросмотр и готовый MP4;
- экспортировать редактируемый FCPXML для Final Cut Pro.

Самый простой сценарий: создать проект, добавить материалы, описать желаемый фильм и нажать «Создать фильм». Получившийся монтаж можно сразу посмотреть или исправить вручную.

## Требования

- macOS 14 или новее;
- Mac с Apple Silicon;
- Xcode Command Line Tools или Xcode;
- Git LFS — для загрузки встроенных бинарных ресурсов Ollama;
- Rust и Cargo — для сборки встроенного движка телеметрии OVRLEY.

## Сборка и запуск

Установите и включите Git LFS:

```bash
brew install git-lfs
git lfs install
```

Склонируйте репозиторий и перейдите в его папку:

```bash
git clone https://github.com/007danlin/VeloEdit.git
cd VeloEdit
git lfs pull
```

Соберите полное приложение:

```bash
./Scripts/build-app.sh
```

Готовое приложение появится в `Build/VeloEdit.app`. Запустить его можно командой:

```bash
open Build/VeloEdit.app
```

## Локальный AI

Режим «Быстро» анализирует лучшие сцены с помощью локальной `qwen3-vl:2b-instruct`. Для AI-чата используется отдельная `qwen3:4b-instruct`. Обе модели работают через Ollama и после установки не требуют интернета:

```bash
brew install ollama
brew services start ollama
ollama pull qwen3-vl:2b-instruct
ollama pull qwen3:4b-instruct
```

Модель для любого выбранного режима анализа также можно загрузить кнопкой внутри VeloEdit.

# Free To Use Music в VeloEdit

Проверено 20 августа 2026 года по официальным источникам:

- [Public API](https://freetouse.com/api)
- [OpenAPI v3](https://api.freetouse.com/v3/openapi.json)
- [Free To Use License](https://freetouse.com/license)
- [Usage Policy](https://freetouse.com/usage-policy)
- [FAQ](https://freetouse.com/faq)

## Технический доступ

VeloEdit использует официальный публичный API v3. Он разрешает поиск, streaming и скачивание музыки, не требует API key или аккаунта. HTML-страницы не скрейпятся.

- Поиск: `GET https://api.freetouse.com/v3/music/tracks/search`
- Перед сохранением выбранного результата загружается полная карточка `GET /music/tracks/{id}`, потому что поиск возвращает только первые теги и категории.
- Аудиофайл берётся только из документированного `files.mp3`.
- Разрешены только HTTPS-файлы с `data.freetouse.com`.
- Premium-треки автоматически исключаются из бесплатной локальной базы.
- На первом запуске после согласия с лицензией загружается по одному треку для шести музыкальных характеров VeloEdit.
- Команда «подбери другой» ищет новый трек через API и исключает уже скачанные provider IDs.

## Лицензия

Free License разрешает non-premium треки только в user-generated content, опубликованном на социальных платформах, и требует корректную атрибуцию. Коммерческий контент, broadcast, digital products и использование без атрибуции требуют соответствующей платной лицензии или подписки.

VeloEdit сохраняет для каждого трека:

- название и автора;
- provider track ID и страницу источника;
- genre, mood/tags, energy, duration и оценочный BPM;
- локальный MP3;
- название лицензии, URL, дату скачивания;
- готовую строку атрибуции и ограничения Free License.

Перед первым автоматическим скачиванием приложение показывает условия и требует согласия. Перед экспортом с Free To Use треком оно повторно показывает ограничения. Кнопка «Атрибуция» копирует требуемый текст для описания публикации.

Музыка не используется для обучения моделей и не генерируется AI. AI-режиссёр только ищет композиции реальных авторов через API, сохраняет их локально и синхронизирует монтажные границы с BPM.

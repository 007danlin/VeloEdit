# Проверка автономного монтажа — 12 сентября 2026

## Что означает обучение

Добавлен импорт **явно одобренного** примера через `veloedit-cli learn-approved-reference <project.veloedit> [taste-profile.json]`. Он читает эталон без изменения проекта и калибрует локальный профиль предпочтений. Веса нейросетевой модели не переобучаются.

Один фильм даёт не более одного наблюдения на признак: медианная длительность планов, отдельно действие/спокойные моменты, размер/длительность/положение/анимация титров и энергия концовки. Конкретные названия глав, песня, запрошенная общая длительность и обработка цвета не становятся универсальными предпочтениями. Существующая проверка регрессий ограничивает применение обновления. Уверенность растёт постепенно.

Отпечаток примера сохраняется атомарно вместе с профилем. Повторный импорт после перезапуска не изменяет профиль. Новые ID таймлайна и фрагментов не превращают тот же фильм в новые наблюдения. Автоматическая генерация не вызывает импорт одобренного примера.

В этой проверке учтён «тест 5 — по идеалу»: восемь наблюдений. Повторный импорт на настоящем профиле не изменил ни одного байта. Резервная копия предыдущего профиля и отчёт сохранены в `Build/AutonomyValidation/`.

## Исправления, обнаруженные широкой проверкой

- Изменение музыки или титров больше не подкрепляет предпочтение неизменённой концовки. Признак концовки извлекается только при изменении её источника или исходного диапазона.
- Синхронное ожидание AVAssetReader вынесено из кооперативных потоков Swift. Полный параллельный прогон ранее зависал при одновременном чтении композиций; стеки показывали заблокированные `copyNextSampleBuffer`. Отмена задачи отменяет reader.
- Повторная проверка evidence больше не запускает ненужную кластеризацию всего архива. Верификатор использует переданные editorial units либо строит их линейно.
- Фраза «без фильтров и телеметрии» ранее запрещала не только HUD, но и исходники с тегом `telemetry-event`. На реальных трёх коротких файлах это давало ложную нехватку материала. Исправлено разделение просьбы об оформлении и исключения темы; старый неудачный черновик также можно продолжить. Явные просьбы выбирать события по телеметрии сохранены.
- Анализатор Qwen3-VL получает JSON Schema с точными номерами и количеством сцен вместо большого примера с нулевыми оценками. Отдельная проверка отвергает лишние/пропущенные/повторные номера и неверные оценки. Техническое качество отделено от интенсивности действия; неподтверждённые выводы о звуке не запрашиваются. Версия кэша увеличена, чтобы повторный анализ не считал старые результаты актуальными. Если пакет содержит неправильные номера, программа один раз повторяет запрос отдельно для каждой сцены; отмена не запускает повтор. Повторный живой анализ трёх оригиналов прошёл без предупреждений.
- Резервная сборка использует подтверждённые свободные диапазоны до проверки минимальной длительности. Короткий промежуточный черновик больше не отбрасывается до попытки дополнения. Запрещённые кандидаты остаются исключёнными, после дополнения повторяются проверки качества и реальных кадров.
- Сравнение временных гистограмм не запускается для семантически разных сцен: раньше вычисленный результат затем всё равно отбрасывался. Формула сходства и пороги не изменены.
- В полном 120-секундном фильме обнаружено вытеснение поздних событий: порядок соблюдался, но ранние главы поглощали весь бюджет. Поиск последовательности теперь резервирует время и число планов для следующих доступных событий/сцен. Пустые события не резервируют время; закрытые главы не открываются повторно. Проверка архива теперь измеряет покрытие занятий, а не только сортировку выбранных фрагментов.
- Разные открытые проекты и CLI перечитывают общий профиль предпочтений перед обновлением и сериализуют запись файловой блокировкой. Проверка двух экземпляров хранилища подтверждает, что одобренный пример учитывается один раз и не стирается следующей правкой другого проекта. Уже запущенную старую версию приложения нужно перезапустить для применения нового поведения.
- Тесты с отдельным Swift-кэшем используют настоящий Rust-мост OVRLEY из собранного приложения. CLI публикуется атомарно, чтобы сборка не перезаписывала исполняемый файл уже запущенной проверки.

## Регрессии

**648 тестов в 16 наборах прошли за 125.495 секунды**, включая исправление короткого резервного монтажа. Окончательный общий лог: `/tmp/veloedit-autonomy-all-passed.log`.

Проверяются импорт, хронология и покрытие глав, повторения, титры, телеметрия, подбор музыки, реальный экспорт, звук, соответствие просмотра экспорту, восстановление, обучение и его сохранение между проектами. Первоначальный параллельный прогон зависал в AVAssetReader; исправленный завершился. Под нагрузкой параллельной компиляции были превышены отдельные тестовые сроки, поэтому итоговые прогоны выполняются последовательно. Проверки не отключались, сроки не увеличивались.

Во время работы другие задачи меняли код приложения. Для воспроизводимого прогона сохранён снимок `Build/AutonomyValidation/source-checkpoint`; исходники приложения сверены с рабочим проектом. В одном тесте исправлено неверное предположение: статический титр виден ровно в startTime, а граница вне интервала проверяется отрицательным временем. Сравнение большого массива пикселей заменено на `elementsEqual`, чтобы диагностический diff тестового фреймворка не занимал минуты. В проверке профиля учитывается секундная точность сохраняемых ISO-дат.

Полный пакет и CLI собираются одним запуском `./Scripts/build-app.sh` с `VELOEDIT_BUILD_CLI=1`. Для финальной сборки используется отдельный Swift-кэш `/tmp/veloedit-autonomy-final-release/swift`, чтобы параллельные сборки не заменяли бинарники. Лог: `/tmp/veloedit-autonomy-final-app.log`. Сборка завершена успешно; проверена строгая подпись полного пакета.

## Проверка реальных фильмов

`Scripts/validate-autopilot.py` создаёт отдельный проект, переносит анализ исходников и независимые APFS-копии кэша, очищает таймлайны/планы/старые подписи. Затем вызывает обычные команды `film` и `render`. Не выбирает конкретные фрагменты и не исправляет полученный монтаж вручную. Поддерживает `VELOEDIT_VALIDATION_CLI` и сохраняет SHA-256 проверенного CLI.

Независимо проверяются порядок исходников, повторения исходных диапазонов, отсутствие фильтра/незапрошенной телеметрии, шрифт титров, покрытие доступных занятий при достаточной длительности и неизменность исходного project.json. Результаты и ограничения — в `Build/AutonomyValidation/*/report.json`.

- `test5-dynamic`: новый автоматический 90-секундный монтаж 12 исходников с 440 кандидатами. 19 планов, пять титров, автоматически выбрана Disco con Tutti. Измерены −16.03 LUFS и −1.34 dBTP. Извлечено 11 кадров, просмотрено восемь. Рыбалка, багги, велосипед и природа представлены последовательно. Сохранились общие названия «В дороге»/«На природе» и повтор «Рыбалка» у двух разнесённых по времени частей.
- `test6-cinematic`: первоначальный полный 120-секундный экспорт отклонён ручным аудитом покрытия: были только первые два события. Сохранён как доказательство ошибки; не выдаётся за итоговый фильм. Повторная проверка `test6-release` завершилась: 120 секунд, 24 плана, все пять групп представлены в хронологическом порядке, шесть титров, без повторов исходных диапазонов. Из 37 исходников 32 не входят в эталон; в итоговом фильме используются 13 таких новых исходников. Выбрана Americana — Kevin MacLeod. Измерены −18.93 LUFS и −4.64 dBTP. Сборка фильма заняла 324.05 секунды; это отдельный прогон, а не строгий сравнительный бенчмарк. Извлечено 12 кадров, просмотрено девять. Эстетические ограничения: крупная деталь багги на вступлении, общий дополнительный титр «В дороге» внутри велопрогулки и общие подписи сохранённого анализа.
- `fresh-import`: шесть оригиналов импортированы и проанализированы с нуля; 15-секундный фильм с велосипедом, без музыки, с исходным звуком, без HUD. Восстановлен после исправления обработки фразы «без телеметрии».
- `fresh-three-retry`: первоначальные три файла без добавления материала дали 15-секундный экспорт после исправления запрета телеметрии. Это причинная проверка исходной ошибки.
- `fresh-vlm`: один оригинал проанализирован новым структурированным запросом, без ошибок и без переноса анализа; группа «Багги».
- `fresh-final`: три оригинала заново проанализированы и дали 15-секундный фильм из четырёх планов. Два пакетных ответа модели не прошли проверку, сработал резервный анализ. Титр «Багги» подтверждён просмотром готового MP4.
- `fresh-recovered`: следующий анализ тех же трёх оригиналов прошёл без предупреждений после добавления восстановления пакета. После исправления резервной сборки получен 15-секундный фильм из трёх разных ракурсов, в порядке исходников. Ноль замечаний quality gate; просмотрены титр и все три плана.

Это проверка программы на конкретных материалах, а не гарантия эстетического совершенства любых исходников. В архивных прогонах анализ сохранённый; отдельно проверен полный первичный анализ небольших наборов. Аудиометрики не заменяют субъективное прослушивание: музыкальный вкус по этим тестам не сертифицируется. Веса нейросетей не переобучались; новые автоматические фильмы не объявлялись одобренными эталонами.

# Семь источников и каскад музыкального поиска

Дата проверки: 10 сентября 2026 года.

Добавлены два независимых источника без ключей API: Audionautix и Scott Buckley. Предыдущие пять источников сохранены. Схема запуска и резервирования описана в [Music-Online-Reliability.md](Music-Online-Reliability.md).

## Audionautix

- Официальный каталог: [Acoustic](https://audionautix.com/free-music/acoustic), аналогичные публичные страницы остальных жанров.
- Автор: Jason Shaw. [Условия использования](https://audionautix.com/creative-commons-music) разрешают использование с атрибуцией CC BY 4.0; сведения сохраняются в проекте.
- Адаптер читает карточки песен: название, длительность, темп, жанр, настроение и прямой MP3. Исключает дубли, короткие заставки и ссылки за пределами музыкального каталога автора.
- Проверка до реализации: каталог HTTP 200, 156 527 байт. Полный `AcousticGuitar1.mp3`: HTTP 200, 6 983 153 байта за 2,13 с.
- Публичная форма поиска POST вернула HTTP 200 с пустым телом; адаптер использует работающие страницы жанров.
- Обнаружен и исправлен HTTP 406: Apache согласует MIME-тип PHP-маршрута до выдачи HTML. Строгий `Accept: text/html` отклоняется, `Accept: text/html, */*;q=0.8` возвращает полный каталог. Исправление проверено настоящим запросом и отдельным регрессионным тестом; User-Agent остаётся VeloEdit.
- robots.txt проверяется перед обращениями; трёхсекундный интервал действует также для повторов временных ошибок. Закрытые разделы не используются.

## Scott Buckley

- Каталог: `https://www.scottbuckley.com.au/library/wp-json/wp/v2/posts`. Используется публичный [WordPress Posts REST API](https://developer.wordpress.org/rest-api/reference/posts/), параметры `per_page=50`, `_fields=id,link,title,content`, сортировка по дате и `search` для названной песни.
- Проверяется лицензия каждой записи и ссылка `MP3 (Full Mix)` на сервере автора. Превью, стемы, защищённые и нелицензированные записи исключаются.
- [Условия автора](https://www.scottbuckley.com.au/library/using-this-music/) требуют атрибуцию; для YouTube она должна быть в описании видео. Автор, источник, лицензия и текст атрибуции сохраняются в проекте.
- До реализации: REST API HTTP 200; полный [Uprising](https://www.scottbuckley.com.au/library/uprising/) — HTTP 200, 8 229 845 байт за 9,02 с.
- В ранжировании участвует описание самой музыки. Списки спонсоров, комментарии и лицензионный текст не используются как музыкальные признаки.

## Проверенная, но не включённая альтернатива

[ccMixter API](https://ccmixter.org/query-api) вернул корректные записи, лицензии и адреса файлов. Однако три разных MP3 от разных авторов вернули HTTP 403. Поэтому ccMixter не включён в рабочую пару резервных источников. Обход запрета скачивания не предпринимался.

## Проверка реализации

Тесты находятся в `Tests/VeloEditCoreTests/MusicCascadeTests.swift`:

- быстрый успех первой ступени не запускает остальные;
- ошибки HTTP, пустая выдача и недекодируемый файл немедленно продвигают каскад;
- зависание запускает резерв через заданный интервал, успех отменяет зависший запрос;
- сбой резерва продвигает каскад даже при зависшей ранней ступени;
- отмена и общий срок ожидания останавливают каскад;
- семь источников распределены по четырём ступеням;
- парсеры проверяют ссылки, лицензии, полные записи, длительности и музыкальные метаданные;
- отдельный opt-in сетевой тест скачивает по два разных полных трека с каждого нового источника через каскад с отказавшей первой ступенью. Проверяет фактическое аудио, длительность, waveform, разные идентификаторы и содержимое файлов. Общего кэша и встроенной музыки в этом тесте нет.

Запуск сетевого теста: `VELOEDIT_LIVE_CASCADE_MUSIC_TEST=1 swift test --disable-sandbox --filter MusicCascadeTests.liveNewSourcesEachDownloadTwoDifferentFullTracksThroughCascade`.

Результаты запуска и полной сборки: [Validation/Music-Cascade.md](Validation/Music-Cascade.md).

Сетевые проверки относятся к текущему подключению. VPN, DNS и прокси не менялись; это не измерение доступности у всех операторов. При недоступности всех источников сохраняется локальный резерв. История последних треков продолжает исключать повторы для новых автоматических видео в пределах доступного каталога.

# Матрица приёмки автономности

Проверено означает наличие указанного доказательства на конкретном уровне. «Частично» не означает прохождение всей релизной приёмки. Unit- и интеграционные тесты не подменяют ручной просмотр, прослушивание, VoiceOver, чистую установку или принудительное завершение процесса на каждом этапе.

Полная релизная приёмка A12 пока не закрыта: для ряда внешних отказов и доступности нет полного сквозного доказательства. Не следует считать все T01–T34 пройденными только по числу автоматических тестов.

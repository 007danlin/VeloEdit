## Уточнение пользователя

Пользователь предпочитает прежний опрос, который составляет описание фильма. В ContentView.swift вопросы снова показываются сразу: формат, длительность, настроение, музыка, звук исходников, титры. Вопрос о телеметрии добавляется только при наличии полезных данных. Кнопка «Создать без опроса» остаётся вторичной; после начала ответов она называется «Создать с текущими ответами». После завершения опроса видны редактируемое описание и основная кнопка «Создать фильм». Состояние шага привязано к проекту, ответы недоступны во время сборки.

В окончательной сборке действительно пройдены все шесть вопросов проекта ui-questionnaire.veloedit. Выбраны 16:9, длительность по материалам, динамичное настроение, отсутствие музыки, сохранение звука и отсутствие титров. Полученное описание видно в UI и сохранено в workspaceState.directorDraft; значения DirectorBrief соответствуют ответам. Доказательство: ../Validation/Autonomy/ui-questionnaire-result.json. Дополнительная генерация по этому опросу не запускалась.

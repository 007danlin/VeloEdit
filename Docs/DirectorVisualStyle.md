# Оформление автоматических фильмов

По умолчанию титры повторяют оформление одобренного «теста 5 — по идеалу»: Avenir Next, 72 pt при 1080p, вес 0.88, белый, слева, позиция (0.36, 0.78), шаблон Minimal Clean. Настроение не меняет шрифт и оформление. Титр главы показывается с первого кадра не менее 3,5 с, если позволяет длина части; длинное название получает больше времени. Он может продолжаться через склейки внутри своей части.

Спокойное настроение задаёт мягкое растворение, киношное — переход через чёрное между событиями и растворение между сценами, динамичное — прямые склейки. Явный запрос без переходов сохраняет прямые склейки. Точное распределение исходных диапазонов также может использовать склейки, чтобы перекрытия не сокращали длительность.

Проверка OCR повышает контраст фона, сохраняя шрифт и расположение. Она не удаляет обязательный заголовок ради прохождения проверки. Неустранённая ошибка читаемости остаётся ошибкой проверки готового фильма.

Без прямого запроса не применяются фильтры, цветокоррекция, декоративная обработка, шумоподавление, эквалайзер и звуковые эффекты. Запрошенная громкость исходников сохраняется. Ручные титры, субтитры и заблокированные клипы сохраняют своё оформление.

Регрессии: `DirectorVisualStyleTests`, `AutopilotDefaultsTests`, `AutomaticEditorialAssemblyTests`. Последний проверяет порядок исходников и глав, первый — в том числе совпадение пикселей с независимым описанием эталона.

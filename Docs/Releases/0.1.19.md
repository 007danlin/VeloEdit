# VeloEdit 0.1.19

- В разделе «Медиа» на монтаже видео и фотографии получили отдельные сетки. В каждой группе материалы идут по времени съёмки. Для одинаковых или неизвестных дат используется порядок имён с учётом чисел.
- Режиссёр понимает просьбы с несколькими адресатами в одной фразе, например обесцветить второй план и показать третий вдвое быстрее.
- В чате можно задать текст начального или финального титра, переименовать его, отменить последнюю правку и вернуть её.
- Исправлено падение при повторном поиске более длинных фрагментов для фильма заданной длительности.

# VeloEdit 0.1.18

- Синяя точка справа от «Умного режиссёра» показывает, что пришёл новый ответ. Это работает и для «Волшебной кисти», и для поля «Что изменить?». Точка исчезает, когда вы открываете режиссёра.
- Такая же точка рядом с «Настройками» сообщает о доступной версии. Нажатие открывает раздел с обновлением и снимает отметку.

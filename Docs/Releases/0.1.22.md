# VeloEdit 0.1.22

- При загрузке установщика VeloEdit теперь ждёт поступления данных до пяти минут. Это помогает завершить обновление при временных перебоях связи.
- Если соединение всё же прервётся по тайм-ауту, окно обновления объяснит причину и предложит повторить попытку.

Изменение начнёт действовать после установки 0.1.22. Если предыдущая версия прерывает загрузку, скачайте DMG из этого релиза.

# VeloEdit 0.1.17

- Исправлены пропуски звука при экспорте MP4 и смещение звука относительно предпросмотра.
- ИИ-режиссёр понимает просьбы поставить переход на каждую склейку и распределить движения камеры по всему фильму. Для таких команд можно обойтись без выделения клипов и ввода таймкодов.
- Режиссёр может выполнить две правки одной командой. Например, по просьбе «сделай начало бодрее, а в конце плавно убери музыку» он сокращает вступление и добавляет затухание уже выбранной музыки.
- После команды «Обновить названия частей» фильм остаётся на паузе. Уведомления VeloEdit появляются без звука.

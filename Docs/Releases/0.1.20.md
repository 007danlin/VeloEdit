# VeloEdit 0.1.20

- В анкете умного режиссёра у каждого ответа теперь видна его настройка: например, «Эффекты и переходы: Много» и «Звук исходников: Приглушить».
- При отправке ответов кнопок режиссёр принимает их как параметры фильма, а не как вопрос о конкретном кадре. Указывать клип или таймкод не нужно.
- При переключении проектов сообщение об остановке предыдущей сборки больше не появляется в чате нового проекта.

# VeloEdit 0.1.25

- Просмотр и экспорт сверяют границы клипа с видеодорожкой исходника. Если файл обрезан, монтажёр сообщает его имя и доступный интервал. На монтажной ленте теперь видно, на каких клипах включён чёрно-белый фильтр.
- Просьба «добавь в конец фрагмент из исходников, где дорога» ищет описанную сцену среди проанализированных материалов и добавляет подходящий неиспользованный фрагмент.
- Команда «покажи скорость на последнем клипе» добавляет спидометр и сохраняет темп воспроизведения. Для клипов без нужных показаний чат сообщает, какие данные недоступны.

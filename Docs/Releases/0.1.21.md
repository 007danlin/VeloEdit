# VeloEdit 0.1.21

- Исправлена остановка сборки из-за тихого звука на отдельных кадрах. Если фильм должен иметь обычную громкость, приложение корректирует готовую дорожку и проверяет её повторно. Явная просьба приглушить звук учитывается отдельно.
- При сбое частоты кадров VeloEdit повторяет аппаратный экспорт сохранённого монтажа. Готовую проверенную копию фильма можно открыть в разделе «Экспорт», пока сохраняется версия другого разрешения.
- Для новых фильмов доступны три режима анализа — «Быстро», «Баланс» и «Качество». Сохранённые задания с профилем «Максимально» сохраняют свой профиль при продолжении.
- Уточнены подбор названий глав и подсказки при знакомстве с интерфейсом. Автоматическая проверка обновлений выполняется раз в час.

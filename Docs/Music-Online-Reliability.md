# Поиск и скачивание музыки — 10 сентября 2026

Подключены семь онлайн-источников: Free To Use, Incompetech, Audionautix, Scott Buckley, Openverse, Internet Archive и общий веб-поиск. Они работают в четыре ступени каскада; побеждает первый завершённый и проверенный аудиофайл.

| Ступень | Источники |
| --- | --- |
| 1 | Free To Use + Incompetech |
| 2 | Audionautix + Scott Buckley |
| 3 | Openverse + Internet Archive |
| 4 | Общий веб-поиск |

Внутри ступени источники запускаются одновременно. Если все попытки последней запущенной ступени завершились ошибкой или пустой выдачей, следующая запускается сразу — даже если более ранний запрос ещё висит. Через три секунды без результата подключается следующая ступень, а ранние запросы продолжают работать до успеха или общего срока ожидания. После получения аудио остальные запросы отменяются. Источники в cooldown пропускаются; незапущенные ступени не получают запросов.

Расширение и проверка двух новых источников: [Music-Cascade.md](Music-Cascade.md).

## Что удалось воспроизвести

На текущем сетевом подключении прямой запрос Openverse не вернул ответ за 15 секунд. Free To Use вернул HTTP 200, но передал только 11 203 байта из примерно 335 КБ и остановился; повтор со сжатием также не завершился за 25 секунд. Это объясняет, почему существовавшие адаптеры могли одновременно не дать трека. Конкретную причину ограничения сети эти измерения не устанавливают.

Официальный каталог Incompetech загрузился: 1 442 записи. Полный MP3 Carefree загрузился с HTTP 200: 6 566 713 байт за 9,93 секунды. Настройки VPN, DNS и прокси не менялись. Это проверка текущего соединения, а не гарантия доступности у всех операторов.

## Изменения

- Audionautix: публичные каталоги жанров, полный список подходящих записей, прямые MP3 Jason Shaw. Соблюдаются robots.txt и трёхсекундный интервал обращений. Форма поиска при проверке возвращала пустой ответ и не используется.
- Scott Buckley: публичный WordPress REST API, до 50 последних записей, отдельный запрос API по явно указанному названию. Принимаются только полные MP3 с лицензией CC BY 4.0 в самой записи. Для ранжирования используется музыкальное описание, а не имена спонсоров и служебный текст.
- Оба новых источника: каталог кэшируется на шесть часов; неизвестная длительность проверяется по реальному аудио до импорта, записи короче 45 секунд отклоняются.
- Incompetech: действующий JSON-каталог, таблица жанров, реальный BPM, длительность, описание, прямой MP3, атрибуция CC BY 4.0. Полный каталог участвует в ранжировании; слишком короткие и некорректные записи исключаются. Каталог повторно используется в памяти до шести часов.
- Free To Use: короткие запросы по стилю, альтернативные термины, до 60 случайно выбранных кандидатов вместо фиксированных 20 лидеров по скачиваниям. Одна некорректная запись не отбрасывает весь ответ. Для получения MP3 больше не обязателен дополнительный запрос карточки трека; поисковая запись уже содержит прямой файл и флаг premium.
- Общий сетевой слой: ограничение размера API-ответа, повтор временных сетевых ошибок и HTTP 408/429/5xx, учёт короткого Retry-After, отмена остальных загрузок после успеха. 403/404 и отмена не повторяются. Длинные ограничения частоты не удерживают операцию.
- Ожидание одного раунда источников ограничено 45 секундами с отменой текущих операций. Запрос конкретной песни может запустить дополнительный раунд поиска альтернативы. Декодирование и копирование локального файла также занимают время.
- Проверка HTTP, размера, полноты загрузки и декодируемого аудио до включения в библиотеку. Проверенные файлы сохраняются в кэш и копируются внутрь проекта.
- При неудаче свежего поиска используется доступный ещё не использованный трек из общего кэша, затем локальная библиотека. История учитывается при новых автоматических фильмах и смене музыки, включая адаптивные музыкальные секции. Явно названную пользователем песню история не запрещает.
- История распознаёт запись по идентификатору источника и сочетанию названия с автором, чтобы одна песня из двух сервисов не считалась новой. Фактическая музыка после повторной режиссёрской сборки тоже попадает в историю.
- Неудачный ручной онлайн-поиск больше не сообщает «новые треки не требуются».

## Рассмотренные сервисы

| Сервис | Решение и официальный источник |
| --- | --- |
| Incompetech | Подключён. Официальные JSON и адреса MP3, условия CC BY 4.0: [документация каталога](https://incompetech.com/agent-section/). |
| Free To Use | Сохранён и доработан. [API](https://freetouse.com/api) поддерживает случайный порядок, limit и offset. Бесплатные треки используются в пределах [лицензии Free To Use](https://freetouse.com/license), атрибуция сохраняется. |
| Openverse | Сохранён как независимый индекс. Используется API аудио; URL лицензии проверяется, длительность интерпретируется в миллисекундах. |
| Internet Archive | Сохранён; проверяется манифест файлов и лицензия каждой записи. |
| Jamendo | Рабочий вариант дальнейшего расширения после получения собственного client_id. Требует проверки audiodownload_allowed и разрешающей лицензии каждого трека: [официальный tracks API](https://developer.jamendo.com/v3.0/tracks). Чужие демонстрационные ключи не встроены. |
| Freesound | Для оригинальных файлов нужен пользовательский OAuth2; сервис в основном ориентирован на звуки и семплы: [официальный API](https://freesound.org/docs/api/overview.html). Не добавлен как зависимость автоматического саундтрека. |
| Pixabay | [Документированный API](https://pixabay.com/api/docs/) предоставляет поиск изображений и видео. Музыкального endpoint в документации нет; недокументированная схема скачивания не используется как основной источник. |

## Проверка

Результаты тестов и сборки: [Validation/Music-Online-Reliability.md](Validation/Music-Online-Reliability.md).

Недоступность всех внешних сетей не позволяет скачать принципиально новую музыку. На этот случай остаются проверенные файлы кэша и встроенная библиотека; при исчерпании доступных новых записей возможен повтор, чтобы видео не осталось без музыки.

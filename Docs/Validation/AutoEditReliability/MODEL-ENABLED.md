## Как отключить

Закройте VeloEdit, выполните команду и откройте приложение заново:

```sh
defaults write app.veloedit.VeloEdit VeloEditEditingDecisionRankerEnabled -bool false
```

Вернуть включённое состояние по умолчанию:

```sh
defaults delete app.veloedit.VeloEdit VeloEditEditingDecisionRankerEnabled
```

Для отдельного запуска приложения или CLI также поддерживается `VELOEDIT_EDIT_RANKER=off`. Прежняя возможность указать путь JSON через `VELOEDIT_EDIT_RANKER` сохранена. Постоянное отключение имеет приоритет над внешним путём. Новых элементов интерфейса не добавлено.

Нерешённые художественные ограничения C2, сцены с едой и самостоятельного поиска пары перехода из [предыдущего отчёта](/Users/daniellineckij/VeloEdit/Docs/Validation/AutoEditReliability/REPORT.md) этим включением не устранены.

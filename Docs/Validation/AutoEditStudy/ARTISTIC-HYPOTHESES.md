## Материалы и сопоставление с кодом

- [Frame.io: Steve Audette, story-driven documentary](https://blog.frame.io/2017/06/21/3-principals-story-driven-pbs-documentary/). Сначала связь смысловых частей, затем сокращения внутри них. В VeloEdit уже есть Event/Scene, NarrativeHypothesisEngine и распределение времени между сценами. Но найденная сцена проекта 1 объединяет лесной проезд и людей на поляне, а hook/closure часто назначаются первому/последнему кадру. Нужен более мелкий план наблюдаемых эпизодов до выбора кадров с явными основаниями и неизвестными свойствами.
- [Frame.io: Bill Weber, musical approach](https://blog.frame.io/2017/06/19/a-musical-approach-to-cutting-documentaries/). Ритм складывается из содержания и развития последовательностей; отдельная сцена может обходиться без музыки. Это не универсальная формула длительностей. В движке уже имеются MusicSyncEngine, AdaptiveSoundtrack, защита действий/реплик, различные preferredDuration. Проверять следует реальные переходы и монотонность: движение камеры само по себе не доказывает появление новой информации.
- [Adobe: J- и L-склейки](https://helpx.adobe.com/ie/premiere/desktop/edit-projects/trim-clips/perform-j-cuts-and-l-cuts.html). У J-склейки звук следующей сцены предваряет изображение, у L-склейки предыдущий звук продолжается после смены плана. В движке есть отдельные аудиоклипы и ducking, но поиск не выявил специального автоматического планировщика J/L. Перенос звука без подтверждённой связи может исказить событие; это отдельная гипотеза для подходящего материала, а не обязательная обработка всех границ.

## Гипотезы для первых сравнений

H1 — контекст перед участниками. Если фильм начинается с людей/подготовки, а в непосредственно предшествующем наблюдаемом эпизоде того же исходника есть пригодный план обстановки, короткое вступление может улучшить понимание места. Не добавлять его при уже понятном начале, отсутствии подтверждённого контекста, нарушении порядка или защищённых реплик/действий. Основание: явный ответ пользователя A + первый лесной фрагмент B; это одно человеческое предпочтение с оговоркой, не общая обучающая истина.

H2 — сжатие однообразного проезда. Внутри одного источника и эпизода без обнаруженной смены действия сравнить имеющуюся последовательность с версией, сохраняющей вход/выход из участка маршрута и все защищённые события/реплики. Не называть удалённые кадры технически плохими. Не применять при неизвестном содержании, ручных фиксациях или явной заданной длительности. Проверить, не теряются ли атмосфера и ощущение пути.

Первый этап: отдельные включаемые варианты H1/H2 для A/B. Не повышать общий балл и не вводить художественный запрет в технический фильтр. Сохранить основания каждого решения в плане. Показывать реальные короткие экспорты со звуком и таймкодами; ответы пользователя записывать отдельно. H1 и H2 проверяются раздельно, чтобы понимать причину предпочтения.

## Ограничения наблюдений

Теги, VLM summary, Vision-классы и DSP-сигналы — оценки модели, а не человеческое подтверждение всей сцены. Одинаковый eventID не доказывает одновременность. В Balanced нет полного достоверного ASR для каждой реплики; недоступную речь/эмоции нельзя считать отсутствующими или автоматически подтверждёнными. Не придумывать конфликт, кульминацию и завершение путешествия по одному финальному затемнению. Первый/последний кадр обозначает границу монтажа, но сам по себе не доказывает начало/конец события.

В одном сопоставимом участке маршрут сокращён с пяти планов / 23,7667 с до трёх / 15,5667 с; реальный короткий A/B со звуком показан пользователю; оба варианта потребовали другой правки. Ни уменьшение длительности, ни технические проверки не используются вместо человеческой оценки связности.

Дополнительный контроль H2 на той же development-4 завершён: 433,9583 с / 85 планов против 398,0667 с / 77 планов H2. Начальные манифесты равны по содержимому; окончательные анализы частично отличаются, включая перестановку сериализованных наборов и обновлённые observations. Отсутствие сохранённого списка исключений и различия повторных прогонов ограничивают причинный вывод. Уменьшение длительности не считается художественным улучшением.

Показан ещё один A/B по проекту 3: остановка с едой и возврат к маршруту, 15,5 с / 5 планов против 15,7667 с / 7 планов. Это сравнение готовых экспортов со звуком, с разными диапазонами и музыкой; завершённость действий и реплик должен подтвердить просмотр. Пользователь оценил проект 3: «B — действие читается лучше». Это отрицательный художественный результат для данного фрагмента нового монтажа A; технический pass его не отменяет. Для H2 пользователь ответил «Оба требуют другой правки»: победителя и ничьей нет, оба варианта требуют пересмотра. Приоритет уточнён ниже; сокращение само по себе не принято. H1 ещё ожидает оценки. Исходное явное предпочтение A + лес остаётся отдельно и не превращается в общий художественный вес.

Следующая проверяемая гипотеза по проекту 3: связь соседних контекстных и действенных планов важнее удлинения единственного плана с едой. В B сохранены два контекстных плана, другой средний момент и более длинный вид реки; причинный вклад каждого пока неизвестен. Предпочтённая последовательность сохраняется как человеческий пример, без общего веса для числа планов, длительности или «интересности».

Уточнение пользователя по проекту 2: «в Б мне не нравится резкий поворот камеры (он тут очень резкий) и полянку мельком видно. а в А есть дубли полянки многовато». Целевой вариант C сохраняет один читаемый план поляны, убирает лишние повторные виды и не использует средний диапазон B с резким поворотом. Это конкретная проверка сочетания содержания и движения, а не правило сокращать все проезды до трёх планов. Первый вариант C позднее получил предпочтение с оговоркой; см. текущий результат ниже.

Позднее пользователь добавил: «в А есть проблема - телефон загораживает кадр». Первый неэкспортированный черновик C отозван, сохранён для истории. В новом C выбран чистый диапазон 401,03–406,97 с исходника; сомнительные повороты исключены. Отдельная полная копия и журнал правок сохраняют исходный таймлайн. Ответ пользователя получен: C лучше, телефона нет, но нужно сохранить въезд вправо через красивые деревья. Это условное предпочтение, а не одобрение сокращения въезда.

# Проверка музыкального поиска — 10 сентября 2026

## Автоматические проверки

На неизменяемой копии проекта `/tmp/veloedit-music-verified`:

```sh
swift test --disable-sandbox --jobs 2 --filter 'Music|Soundtrack'
```

Результат: **72 теста, 3 набора, 0 ошибок**, 20,297 секунды выполнения после сборки. В этом прогоне внешняя сеть отключена флагами тестов; сетевые проверки выполнены отдельно ниже.

Проверены переключение между источниками и отмена зависшего запроса, общий тайм-аут, повтор HTTP 503, отсутствие повторов 403 и отмены, ограничение размера JSON, частично некорректная выдача Free To Use, разбор каталога и лицензий Incompetech, поиск конкретных песен, исключение повторов между сервисами, независимая копия кэша в новом проекте, офлайн-резерв, адаптивные секции, экспорт и плавное завершение музыки.

Исправлены две проверки, мешавшие воспроизводимому прогону: ожидание фонового аудиоанализа теперь ограничено явным сроком в 10 секунд вместо 2 секунд под нагрузкой; проверка сетевой гонки предварительно декодирует аудиофикстуру, чтобы измерять отмену источника. Проверка громкости согласована с уже изменённой политикой `DirectorSourceAudioPolicy.duck`, а несовместимая с макросом Swift Testing передача `allSatisfy(\.isFinite)` заменена равнозначным замыканием.

## Реальная сеть и аудиофайлы

```sh
VELOEDIT_LIVE_MUSIC_TEST=1 VELOEDIT_LIVE_INCOMPETECH_TEST=1 \
  swift test --disable-sandbox --jobs 2 --filter 'Music|Soundtrack'
```

Два сетевых теста прошли:

- `liveIndependentProviderDownloadsTwoDifferentPlayableTracks`: 7,800 секунды. Happy Alley — **3 316 821 байт**, Aurea Carmina — **8 447 095 байт**. Проверены длительность ≥45 секунд, различие файлов и записей, чтение аудио AVFoundation и непустой результат анализа звуковой волны.
- `liveOnlineReplacementDownloadsTwoDifferentAudioFilesWhenEnabled`: 21,346 секунды. В гонке Free To Use, Openverse, Incompetech, Internet Archive и общего веб-поиска скачаны **Action** и **Guess Who**, оба через Incompetech. Проверены разные идентификаторы и содержимое MP3.

В этом предварительном общем прогоне были ошибки ожидания фоновой загрузки и устаревших ожиданий громкости; они исправлены и перепроверены итоговым прогоном из 72 тестов выше. Оба сетевых сценария завершились успешно уже в предварительном прогоне.

Дополнительная прямая проверка официального источника: `Carefree.mp3`, HTTP 200, **6 566 713 байт**, 9,93 секунды. Каталог `pieces.json` — 1 442 записи. VPN/DNS/прокси не перенастраивались; доступность подтверждена только для текущего соединения.

## Сборка приложения

Полная сборка выполняется штатным `./Scripts/build-app.sh` из той же неизменяемой копии. Исходники в рабочем каталоге одновременно изменялись другими процессами, поэтому сборка непосредственно из рабочего каталога прерывалась диагностикой Swift «input file was modified during the build».

**Результат:** полный release-bundle успешно собран и подписан. `codesign --verify --deep --strict` после переноса прошёл; исполняемый файл побайтно совпадает с проверенной сборкой.

Готовое приложение: `Build/MusicSearch/VeloEdit.app`. В `Build/VeloEdit.app` к моменту публикации уже находилась более новая сборка другого процесса (16:58:11 против среза исходников 16:53:26), поэтому проверенная музыкальная сборка сохранена в отдельном каталоге, без замены этой более новой сборки. Изменения музыкального поиска находятся и в основном рабочем дереве.

Хеши исходников проверенной сборки: [Music-Online-Build-Source-Hashes.json](Music-Online-Build-Source-Hashes.json).

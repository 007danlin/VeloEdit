# Оформление автоматических фильмов

По умолчанию названия частей повторяют оформление одобренного «теста 5 — по идеалу»: Avenir Next, 72 pt при 1080p, вес 0.88, белый, слева, позиция (0.36, 0.78). Этот эталон зарегистрирован в библиотеке как «Глава компактная» (`title.chapter-compact.v1`) с точным сохранением горизонтального рендера прежней конфигурации Minimal Clean. Настроение не меняет оформление глав. Титр главы показывается с первого кадра не менее 3,5 с, если позволяет длина части; длинное название получает больше времени. Он может продолжаться через склейки внутри своей части.

Название всего фильма имеет отдельную роль `filmOpening` и собственное оформление из общей библиотеки. Настройка «Название фильма в начале» предлагает авто, выбор оформления и выключение. Если начальный титр пересекается с первой главой, её подпись переносится только внутри своей части либо объединяется с названием фильма; неразрешимый конфликт сохраняет название части и показывает предупреждение. При выключении вступления исходное время главы восстанавливается. Подробности — в [спецификации начальных титров](../Specifications/film-opening-titles.md).

Спокойное настроение задаёт мягкое растворение, киношное — переход через чёрное между событиями и растворение между сценами, динамичное — прямые склейки. Явный запрос без переходов сохраняет прямые склейки. Точное распределение исходных диапазонов также может использовать склейки, чтобы перекрытия не сокращали длительность.

Проверка OCR повышает контраст фона, сохраняя шрифт и расположение. Она не удаляет обязательный заголовок ради прохождения проверки. Неустранённая ошибка читаемости остаётся ошибкой проверки готового фильма.

Без прямого запроса не применяются фильтры, цветокоррекция, декоративная обработка, шумоподавление, эквалайзер и звуковые эффекты. Запрошенная громкость исходников сохраняется. Ручные титры, субтитры и заблокированные клипы сохраняют своё оформление.

Регрессии: `DirectorVisualStyleTests`, `AutopilotDefaultsTests`, `AutomaticEditorialAssemblyTests`. Последний проверяет порядок исходников и глав, первый — в том числе совпадение пикселей с независимым описанием эталона.

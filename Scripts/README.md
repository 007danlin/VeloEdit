# Скрипты VeloEdit

Все команды запускаются из корня проекта. Скрипты сборки остаются прямо
в `Scripts/`, чтобы сохранить привычные команды и пути в автоматизации.

| Задача | Команда |
| --- | --- |
| Полный bundle приложения | `./Scripts/build-app.sh` |
| Быстрая сборка для разработки | `./Scripts/dev-build.sh --jobs 2` |
| Swift-тесты | `./Scripts/dev-test.sh --jobs 2` |
| Тесты Python-инструментов исследований | `python3 -m unittest discover -s Tests/Study -v` |
| Тесты инструментов распространения | `python3 -m unittest discover -s Tests/Distribution -v` |

Порядок подготовки DMG, подписи и проверки лицензий описан в
[инструкции по выпуску](../Docs/Guides/release.md).

| Подпапка | Назначение |
| --- | --- |
| [Validation](Validation/) | Проверки AI, речи, титров, монтажа и готового bundle |
| [Performance](Performance/) | Замеры производительности и сводки трассировок |
| [Studies](Studies/) | Эксперименты с монтажом, подготовка данных и обучение ранжирования |
| [Tools](Tools/) | Вспомогательные Swift-инструменты для проверки экспорта и стилей |

Скрипты исследований могут требовать локальные медиа, проекты и результаты
предыдущих прогонов. Часть из них запускает приложение, создаёт проекты или
рендерит видео; перед запуском проверьте параметры и входные пути в скрипте.
Это отдельные инструменты, они не выполняются автоматически при сборке.

Исполняемые проверки хранятся в Git. Их результаты размещаются в
`Local/Reports/`, `Build/` или `output/` и игнорируются Git.
